# Iteration 6 — Full gas UX

Эта итерация усиливает только пользовательский frontend и не требует новых backend-полей.

## Что добавлено

- Cinematic autoplay для recap: история может проигрываться сама, но остаётся управляемой вручную.
- Опциональный UI sound design на Web Audio API. По умолчанию звук выключен.
- Публично безопасный «Трейлер года» на основе только SHARE payload.
- Resume-механика через localStorage: незавершённую историю можно продолжить с сохранённого экрана.
- Интерактивный портрет поведения на основе существующего `evidence`.
- Декоративный secret visual bonus для сочетаний ачивок. Он явно не выдаётся за backend-achievement.
- Pointer physics / tilt для story-card на desktop и отключение через `prefers-reduced-motion`.
- Живой фон recap, который меняется по tone/motif текущей карточки.
- Frontend-only self insight на `YEAR_ACTIVITY`: выделяется максимум среди уже переданных счётчиков, без сравнения с другими пользователями.
- Before/after preview на `NEXT_ACTION`.
- Персональная финальная фраза по уже переданному behavior code.
- Карта «Моменты года» остаётся альтернативной навигацией после первого полного просмотра.
- Тизеры и визуальные пасхалки на экране тестовых профилей.
- Расширенный SHARE editor: шаблон, 4:5/1:1, светлый/цветной фон, включение/скрытие только тех публичных полей, которые реально присутствуют в SHARE payload.
- PNG export учитывает выбранный формат и безопасные настройки.

## Принцип data-faithful UX

Все новые эффекты строятся только из уже существующих полей:

- `behavior.code`, `score`, `evidence`;
- `categoryCode`, `category`, `categoryViews`;
- `month`;
- achievement codes + `recap.achievements`;
- `nextAction` + typed target;
- минимальный публичный SHARE payload.

Никаких процентов относительно других пользователей, точных данных активного месяца, «редкости» ачивок или других несуществующих метрик frontend не придумывает.
